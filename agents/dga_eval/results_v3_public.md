# Opt-in model v3-public

Generated by `train_public.py`. A hashed 1-5-gram logistic regression trained on all 25 public DGA families and Tranco V354N (the 200,000 normal names `public_bench.py` tests on are held out). How well this recipe catches families it never saw is in [results_public.md](results_public.md) (row `lr-v3`, unseen families).

Regularisation 3e-06, chosen on 5 held-out families (emotet, gozi, kraken, padcrypt, ramnit): 1e-06 41.1%, 3e-06 43.6%, 1e-05 43.2%, 3e-05 40.2%, 0.0001 39.2% caught at 0.1% false positives.

## Thresholds

Each default threshold is moved to the v3 score that flags the same share of the held-out normal names as the shipped models do at that default.

| Setting | Shipped default | Normal names flagged | v3-public value | Normal names flagged |
|---|---|---|---|---|
| `recommend_threshold` | 0.96 | 0.52% | 0.981287 | 0.52% |
| `block_threshold` | 0.995 | 0.13% | 0.998903 | 0.13% |
| `corroborated_threshold` | 0.8 | 1.69% | 0.860945 | 1.69% |
| `burst_min_score` | 0.8 | 1.69% | 0.860945 | 1.69% |
| `beacon_min_dga` | 0.5 | 6.76% | 0.419535 | 6.76% |

These are measured on Tranco names, which are popular sites: a home network also looks up less popular names, so expect more alerts than the table suggests in the first week, as with the shipped models.
